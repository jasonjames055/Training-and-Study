About the score

ISC2 scores CAT exams with item response theory, so there is no published conversion from percent correct to the 700 scaled score. This practice test reports percent correct × 1000 as an estimated scaled score, so 70% correct = 700. Most instructors suggest aiming for 80%+ on practice sets before booking, because real items are harder and adaptive. The real exam also includes 25 unscored pretest items and advanced item types that this file does not reproduce.
